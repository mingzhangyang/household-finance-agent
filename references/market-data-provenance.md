# Historical annual returns reference fixture (partial)

This file contains 19 *manually transcribed, rounded-to-two-decimal-place* annual observations (2000–2018) from Aswath Damodaran's NYU Stern historical U.S. annual investment return table (stocks include dividends; bonds are 10-year Treasury total return):
https://pages.stern.nyu.edu/adamodar/New_Home_Page/datafile/histretSPX.html

This **is not a full calibration dataset** and should not be used to represent a multi-decade retirement outcome distribution. Treat this as a source-identified import and regression-test fixture only. Before professional use, download the full dated source data, independently check the columns against the primary source, record the SHA-256 digest, and rerun the calibration and out-of-sample checks. No data after 2018 is asserted by this fixture.
